# Actualización del Cliente de MercadoPago

## Cambios Realizados

### 1. **Configuración (src/core/config.py)**
Se agregaron dos nuevas variables de configuración:
- `WEBHOOK_BASE_URL`: URL base para el webhook (ej: "https://bazaar.pib.ar")
- `BAZAAR_BASE_URL`: Base URL para los deep links de Bazaar (ej: "bazaar://order-polling")

```python
WEBHOOK_BASE_URL: str = "https://payments.example.com"
BAZAAR_BASE_URL: str = "bazaar://order-polling"
```

### 2. **Cliente MercadoPago (src/services/mercadopago_client.py)**
La función `create_preference()` fue actualizada para incluir:
- Parámetro `notification_url`: URL donde MercadoPago enviará las notificaciones
- Parámetro `back_urls`: Diccionario con URLs de retorno (success, pending, failure)

El payload enviado a MercadoPago ahora incluye:
```json
{
  "items": [...],
  "external_reference": "order_id",
  "notification_url": "https://bazaar.pib.ar/payments/mp-webhook",
  "back_urls": {
    "success": "bazaar://order-polling/{order_id}",
    "pending": "bazaar://order-polling/{order_id}",
    "failure": "bazaar://order-polling/{order_id}"
  }
}
```

### 3. **Servicio de Pagos (src/services/payment_service.py)**
La función `create_preference()` en el servicio ahora:
1. Obtiene las URLs de configuración
2. Construye la `notification_url` completa
3. Interpola el `order_id` en los `back_urls`
4. Pasa estos parámetros al cliente MercadoPago

## Flujo de Webhooks

### Recepción y Validación
1. MercadoPago envía el webhook a `/payments/mp-webhook`
2. Se valida la firma usando `webhook_validator.py`:
   - Extrae `ts` y `v1` del header `x-signature`
   - Construye el manifest: `id:{data_id};request-id:{x_request_id};ts:{ts};`
   - Valida usando HMAC-SHA256 con el secret configurado

### Procesamiento
1. Se extrae el `data.id` del webhook
2. Se valida la firma
3. Se obtiene el payment info de MercadoPago
4. Se actualiza el estado local en la BD
5. Se notifica al servicio de Órdenes

## Variables de Entorno Necesarias

```env
WEBHOOK_BASE_URL=https://bazaar.pib.ar
BAZAAR_BASE_URL=bazaar://order-polling
```

O utilizar los valores por defecto durante desarrollo.

## Validación de Firma del Webhook

El `webhook_validator.py` ya implementa la validación correcta según el estándar de MercadoPago:
- Método: HMAC-SHA256
- Manifest format: `id:{data_id};request-id:{x_request_id};ts:{ts};`
- Secret: Se obtiene de `settings.MP_WEBHOOK_SECRET`
